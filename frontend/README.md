# Quiz App — Static Frontend

Only the **UI** of the Quiz App. There is **no backend connection** here:
- no `axios`, no `api/` folder, no `.env`
- no `store/` (Context) and no `hooks/`
- data is hardcoded (1 sample question, score 7/30)

Buttons only switch between the 3 screens so you can see every screen.

```
npm install
npm start
```

See `../dynamicfrontend/BUILD_STEPS.md` for how logic is added on top of this UI step by step.
